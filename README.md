# ARBUZ · Sovetskaya Gavan — investor landing page

Инвесторская страница для ТЦ «Арбуз» и капитального склада в Советской Гавани. Основная и единственная редактируемая версия — **русская** (`index.html`). Английская копия `index-en.html` заморожена: изменения вносятся **только в `index.html`**.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | **Основная версия — русская.** Самодостаточная страница: HTML + CSS + JS. Открывается двойным щелчком с диска, работает без сборки и без интернета; внешних запросов нет. Manrope используется, если установлен в системе, иначе — `Segoe UI / system-ui`. Все правки — здесь. |
| `index-en.html` | Замороженная английская копия того же макета (последняя синхронизация — замена карты в разделе «Резюме»). Не редактируется. Переключатель **RU / EN** в верхней панели линкует страницы друг на друга (`index.html` ↔ `index-en.html`), поэтому обе открываются с диска без сервера. |
| `assets/presentation-arbuz-sovetskaya-gavan.pdf` | Оригинальная презентация, 15 слайдов. Кнопки **Открыть PDF / Скачать** в разделе `#deck`. |
| `assets/investment-memorandum-arbuz.pdf` | Текстовая инвестиционная записка. Ссылка **Меморандум (PDF)**. |
| `assets/slides/slide-01.jpg … slide-15.jpg` | Полные слайды для встроенного просмотрщика. Это производные JPEG от исходных PNG: кадрирование не выполнялось. |
| `assets/thumbs/thumb-01.jpg … thumb-15.jpg` | Уменьшенные копии тех же полных слайдов для ленты миниатюр. |
| `assets/bam-sovetskaya-gavan.jpg` | Карта Байкало-Амурской магистрали (1280×624) — в разделе «Резюме». Источник: IZ.RU, водяной знак на карте сохранён. |
| `tools/translate_ru.py` | Историческая миграция: сборка русской версии из английской. Больше не нужен — `index.html` ведётся вручную; скрипт специально отказывается перезаписывать файл без ключа `--force`. |

## Рабочий процесс

- Правки вносятся **только в `index.html`** (русская версия, основная).
- `index-en.html` не трогаем: английская версия зафиксирована на текущем состоянии.
- После правок обязательно проверяем: консоль без ошибок, отсутствие горизонтального скролла на 375 / 768 / 1440, печать A4.


## Как открыть

1. Откройте `index.html` двойным щелчком в Chrome / Edge / Firefox — это русская версия.
2. Переключатель **RU / EN** в шапке ведёт на английскую версию `index-en.html` и обратно.
3. Раздел **Презентация** в верхнем меню — просмотр 15 слайдов стрелками, клавишами `←` / `→` или по миниатюрам.
4. Кнопки **Открыть PDF** и **Скачать** ведут на локальный PDF. Для отправки страницы заказчику передавайте папку целиком (`index.html` + `index-en.html` + `assets/`).

## Контактные плейсхолдеры — 5 штук

Токены есть в **обоих** файлах (`index.html` и `index-en.html`). Найдите и замените:

| Токен | Поле |
|---|---|
| `{{OWNER_NAME}}` | Владелец / компания / брокер |
| `{{OWNER_ROLE}}` | Должность, например Head of Asset Management |
| `{{TELEGRAM_HANDLE}}` | Telegram, например `@your_handle` |
| `{{WHATSAPP_NUMBER}}` | WhatsApp, например `+7 900 000-00-00` |
| `{{EMAIL_ADDRESS}}` | E-mail, например `name@example.com` |

После замены токенов обновите `href` у четырёх контактных ссылок и у кнопок `mailto:` — сейчас там стоят демонстрационные значения (`your_handle`, `79000000000`, `name@example.com`). Это сделано намеренно: плейсхолдеры видны в интерфейсе и не дадут случайно опубликовать чужие контакты. Токены также продублированы в HTML-комментариях рядом с полями.

## Презентация

- PDF-файл презентации лежит в `assets/presentation-arbuz-sovetskaya-gavan.pdf`.
- Чтобы обновить презентацию: замените PDF и перезапишите `assets/slides/slide-01.jpg … slide-15.jpg` (ширина 1623 px, высота 898 px) и миниатюры в `assets/thumbs/`. Количество слайдов в просмотрщике задаётся в `index.html` (и в `index-en.html`) и в разметке ленты миниатюр.
- Все изображения слайдов показываются целиком, без вырезания фотографий.

## Русская версия — что учтено

- Русская версия была собрана из английской машинным переводом (словарь + локализация чисел: пробел-разделитель тысяч, запятая для десятков, «25 ноября 2026») и с тех пор ведётся вручную как основной файл.
- Числа и формулировки сверены с английской версией: 40,9% и 30,4% считаются от разных ориентиров и не суммируются; «69%» на странице отсутствует.
- В компактных плитках валюта дана символом (23,1 млн ₽, 160,59 млн ₽, 531,62 млн ₽), в прозе — «млн руб.»; значения не переносятся на две строки.
- В водопаде дисконта подписи колонки вынесены левее столбцов, белое значение 368,38 полностью внутри зелёного столбца.

### Скрипт пересборки (не нужен для работы)

`tools/translate_ru.py` остался как историческая миграция: он читает `index-en.html` и пересобирает из него русскую версию. Сейчас он **защищён** — без явного ключа `--force` откажется перезаписывать `index.html`, чтобы правки ручной версии не потерялись:

```bash
python tools/translate_ru.py            # откажется перезаписывать index.html
python tools/translate_ru.py --force    # принудительная пересборка из английской
```

Если понадобится пересобрать русскую версию из английской, помните: все текущие правки русской версии будут потеряны. В конце скрипт печатает `missing N` — число непереведённых строк; если `N > 0`, добавьте их в словарь `D` в начале скрипта.



## Если нужно заменить схему на реальное фото

В макете нет пустых фотографических слотов: все визуалы — векторные схемы (V1–V9) или полные слайды презентации. Если позже понадобится добавить оригинальное фото, используйте готовую рамку `.artframe` (герой) или `.planframe` (раздел Asset) и замените внутренний `<svg>` на:

```html
<img src="assets/your-photo.jpg" alt="Описание" style="width:100%;height:auto;border-radius:16px;object-fit:cover">
```

Рамка задаёт ширину и отступы, поэтому сетка не сломается. Если фото ещё нет, сделайте пустой слот по правилу R2 промта: рамка `1px dashed #CBD5CC`, фон `#F4F7F5`, подпись `PHOTO — what belongs here` 14 px приглушённым цветом.
